Installation Guide

Get the modpack installed and connected to the server using the Prism Launcher (also works with the Modrinth App).

Before you start: Make sure you have a valid Minecraft Java Edition account and at least 4–6 GB of RAM allocated for smooth performance with this many mods.
1

Install Prism Launcher

Download and install Prism Launcher for your operating system (Windows, macOS, or Linux). Prism is a free, open-source launcher that manages Forge versions and mods automatically.

2

Create a New Instance

Open Prism, click Add Instance, and select the correct Minecraft version and Forge loader version for this pack (see the pinned announcement in Discord for the exact version numbers).

3

Import the Modpack (Recommended)

If a .mrpack export is provided by the server admin, use Prism's Add Instance → Import option and select the file. This automatically downloads all 139 mods with the correct versions.

  • If no pack file is provided, manually download each mod from the Mod List page, matching the exact Minecraft and Forge versions.
  • Place downloaded .jar files into your instance's mods folder.
4

Allocate Memory

In the instance settings, go to Java and set the minimum/maximum memory to at least 4096–6144 MB depending on your system's available RAM.

5

Launch and Verify

Start the instance. On first launch, mod loading may take a few minutes as Forge indexes all mods. If you see a crash report, check the FAQ for common fixes.

6

Connect to the Server

From the Multiplayer menu, click Add Server and enter the server address provided by the admin team. Join and enjoy!

Recommended Client Mods

These aren't required but improve your experience: Sodium and Iris for performance and shader support, Jade for block/entity info, and Xaero's Minimap for navigation. All are already included in the server's mod list.
